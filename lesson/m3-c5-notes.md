Migration Contract

Inputs:

completed example #1
completed example #2
migration rules
constraints

Outputs:

repeatable execution

Example:

DO

replace Bootstrap buttons
preserve accessibility
preserve tests
keep component behavior

DON’T

redesign layouts
rename unrelated components
introduce new abstractions

Key idea:

We are defining the transformation, not asking AI to improvise.
------
Warning:

Don’t scale before standardizing

Bad:

15 inconsistent migrations

Good:

2 reviewed examples
→ migration contract
→ 15 consistent migrations

Call out:

AI accelerates both good and bad patterns.
